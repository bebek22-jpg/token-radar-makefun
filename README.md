Token Radar — pre-token protocols ranked by implied value. Every category multiple is calibrated at run time from the snapshot's own live-token protocols (median mcap/TVL per category), so the ranking is a model of the snapshot's figures, not a hand-picked list. The dashboard is sortable and filterable, with a per-protocol detail view showing the model's line-by-line breakdown and a concrete farm plan with costs and time. Entry for the [token-radar-01 bounty](https://make.fun/bounty/token-radar-01) on make.fun.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
